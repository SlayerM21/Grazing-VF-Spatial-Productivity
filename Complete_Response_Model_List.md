## Model codes

Codes describe the structural model; exact source column names and responses are retained in each full formula below.

| Code | Structure |
|---|---|
| S | `response ~ TRT * SR + (1 | Year) + (1 | Pasture)` |
| P | `response ~ TRT * SR + Period + (1 | Year) + (1 | Pasture)` |
| A | `response ~ TRT * SR + Period + (1 | Year) + (1 | Pasture)` |
| F | `response ~ TRT * SR + RotationPeriod + (1 | Year) + (1 | Pasture)` |
| C | `response ~ IBW + TRT * SR + (1 | Year) + (1 | Pasture_ID)` |
| Q | `response ~ TRT * SR + Period + (1 | Year) + (1 | Pasture)` |

Pasture_ID/Pasture identify physical pastures. RGP/Period/RotationPeriod identify grazing periods. Global GreenFeed F uses the literal Year grouping column and RotationPeriod fixed-effect column. F has the same structure and observations as the Global primary source model; the former fixed-year sensitivity is removed rather than fitting the same question twice. A and Q use the same requested random structure as P; their animal observation units and Q eligibility rule remain distinct.

All period models retain TRT, SR, and TRT:SR fixed effects and add Period (or the source RGP/RotationPeriod column) as a main effect. No TRT:Period, SR:Period, or TRT:SR:Period interaction is fitted. Management differences are therefore assumed constant across periods within each retained model. A complete TRT × SR × Period EMM prediction grid can still describe the adjusted combinations; that grid does not add interactions to the fitted formula. S and the IBW-adjusted C model are unchanged.

Pasture_Year, PastureYear, Animal_Year_ID, and Steer_ID may remain identifier/QC columns; they are not random effects in the requested formulas. The requested animal-period model has no animal intercept or explicit within-animal residual correlation term, and the pasture-period model has no separate pasture-year term. Those residual-correlation limitations should be considered when interpreting model-based SEs and P-values.

No separate management LMM is specified for grazing velocity or bout duration, GPS coverage/fix counts, assigned-RGP active percentage, animal density/animal-day density, and the other map/QC quantities not named in the model entries above. BW spline curves, fitted daily BW, first/second derivatives (daily gain/acceleration), algebraic regression slopes, endpoint ADG, descriptive correlations/R-squared and LOESS curves are descriptive or processing outputs. stats::smooth.spline() describes each steer-year BW trajectory; it is not an additional treatment-comparison LMM.

Combined CH4 + CO2 calculations, land-area ratios, liveweight-gain intensities, and their models were removed at the user request. Separate CH4 and CO2 responses remain.

All inferential models use Gaussian LMMs with the requested Year/Pasture random intercepts; the protected monthly models and the IBW-adjusted final-weight ANCOVA retain their prior formulas. Independent pasture-treatment replication remains limited; repeated animals, years, and periods do not create independent treatment replicates. These specified covariance terms do not separately model animal-level or pasture-year residual correlation.

Actual scientific fits, sample sizes, estimates, tests, and exports have not been executed because the input datasets were unavailable. Optional qualification thresholds gate only the separate sampling-qualified GreenFeed models; the main RGP_CH4_g_day and RGP_CO2_g_day specifications remain in the code.
